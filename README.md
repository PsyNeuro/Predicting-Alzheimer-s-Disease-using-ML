# Predicting-Alzheimer-s-Disease-using-ML

Alzheimer's disease is a serious neurodegenerative disorder characterised by pathologies in memory, language, and intelligence, among others. The pathology starts early in life and the patient is asymptomatic, hence research is currently being undertaken to identify which brain areas can be used to identify which individuals go on to develop Alzheimer's disease. Some candidate regions, like medial temporal lobe, responsible for memory are promising candidates. 

The current project uses machine learning methods in conjunction with structural MRI measures to attempt to predict which individuals have Alzheimer's disease or are healthy. 

Data attached is a random array of numbers, so the models should not work with it, but its there for you to check the code runs
